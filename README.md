# Droplets

Droplets for [Droppy](https://getdroppy.app), the Dynamic Island and shelf
for Mac. One folder per droplet, each a Swift package built with
[DroppyKit](https://getdroppy.app/docs/droppykit).

| Droplet | What it does |
| --- | --- |
| [Science Status](science-status/) | Claude Science sessions in the notch: a live pill while one runs, a shelf list of recent sessions, and a card when one finishes or needs input. |

Each folder's README says how to build, test and run it. Released
droplets install from the Droppy Store.
